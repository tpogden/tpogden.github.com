016: Running Up That Hill (A Deal with Metropolis)

2026-10-15

Last time the darts ran out of room. In twenty dimensions the thing being measured was a billionth of the box and nearly every dart missed. A dart knows nothing about where it landed so it cannot do better.

A walker can. It can feel whether the ground is higher or lower where it is about to step. This post is about the simplest use of that: a walker that spends its time on a landscape in proportion to how high it is.

The map below is a landscape with two hills. The lines are contours. Each white dot is a walker, with the line behind it showing where it has been and each step goes like this:

  1. Propose a small step in a random direction.
  2. If the new spot is higher, take it.
  3. If it is lower, take it with probability (new height) / (old height), like a coin that is weighted by how much is lost. Otherwise stay where you are.

A rejected step is the yellow dot. That is the whole algorithm. It is the Metropolis method and the walker never needs to know what the landscape adds up to, only how its height compares between two nearby places.

The grey is the landscape: the higher the ground, the lighter. The red builds up as walkers visit and it is strongest where they have been most. When the rule works the red fills the hills and nothing else and its shape matches the contours underneath. A small yellow dot is a step that was rejected: the walker stays where it was.

Try these:

  • Turn the rule off. With Always step every proposal is accepted, so the walkers diffuse everywhere and ignore the hills. The red smears flat across the whole map, and each trail is a Brownian path: a step in a random direction, then another.
  • Make the step very small, then very large. A small step is nearly always accepted but crawls so the walkers take a long time to get anywhere. A large step often lands somewhere low and is rejected so the walkers sit. The acceptance rate in the readout is what changes. Somewhere in between, a quarter to a half of steps accepted, is the quickest way to cover the map.
  • Look at the two hills. The right-hand one is a third as high but a good deal wider. Walkers spend more of their time there because what counts is the whole hill and not just its top.

It starts with three walkers so that each one can be followed. Walkers goes up to a hundred: more of them fill the map in faster and make the charts smooth but they all do the same thing. Step size is how far a proposal can go, Steps/s is the speed, and Rule switches between Metropolis and always stepping. Restart puts the walkers back at random places.

  // The landscape: a tall narrow hill and a much lower, wider one. The same function is
  // used on the GPU to walk and in JavaScript for the exact answer.
  const hills = [
    { x: -1.6, y: 0.3, height: 1.0, spread: 0.35 },
    { x: 1.6, y: -0.3, height: 0.35, spread: 0.9 },
  ];
  const heightAt = (x, y) =>
    hills.reduce(
      (h, c) =>
        h + c.height * Math.exp(-((x - c.x) ** 2 + (y - c.y) ** 2) / (2 * c.spread ** 2)),
      0,
    ) + 1e-9;
  const landscapeWGSL = `
      fn height(p: vec2f) -> f32 {
        var h = 1e-9;
        ${hills
          .map(
            (c) => `{
          let d = p - vec2f(${c.x}, ${c.y});
          h += ${c.height} * exp(-dot(d, d) / ${2 * c.spread ** 2});
        }`,
          )
          .join("\n")}
        return h;
      }`;

      @group(0) @binding(3) var<storage, read_write> rng: array<u32>;

      // Steps proposed, steps accepted
      @group(0) @binding(5) var<storage, read_write> stats: array<atomic<u32>, 2>;
      // The last ${trail} positions of every walker, a ring of ${trail} rows
      @group(0) @binding(6) var<storage, read_write> history: array<vec2f>;
      // Steps each walker has spent in the left half of the map
      @group(0) @binding(7) var<storage, read_write> leftSteps: array<u32>;

      ${random.rngWGSL}
      ${landscapeWGSL}

      const halfSize = vec2f(${halfWidth}, ${halfHeight});

      // Wrap a point round the edges of the map
      fn wrap(p: vec2f) -> vec2f {
        return p - 2.0 * halfSize * floor((p + halfSize) / (2.0 * halfSize));
      }

      @compute @workgroup_size(${groupSize})
      fn walk(@builtin(global_invocation_id) id: vec3u) {
        if (id.x >= params.walkers) { return; }
        var p = positions[id.x];
        var state = rng[id.x];
        var accepted = 0u;
        var left = 0u;

        for (var k = 0u; k < params.steps; k++) {
          let q = wrap(p + gaussian2(&state) * params.stepSize);
          var accept = true;
          if (params.metropolis == 1u) {
            // Take a higher spot; take a lower one with probability new / old
            accept = rand(&state) * height(p) < height(q);
          }
          proposals[id.x] = vec4f(q, select(1.0, 0.0, accept), 0.0);
          if (accept) {
            p = q;
            accepted += 1u;
          }
          if (p.x < 0.0) { left += 1u; }
          let row = (params.head + ${2 * trail}u - params.steps + k) % ${trail}u;
          history[row * ${maxWalkers}u + id.x] = p;
          let cell = vec2u((p / halfSize * 0.5 + 0.5) * vec2f(${binsX}.0, ${binsY}.0));
          let binRow = ${binsY - 1}u - min(cell.y, ${binsY - 1}u);
          atomicAdd(&counts[binRow * ${binsX}u + min(cell.x, ${binsX - 1}u)], 1u);
        }

        positions[id.x] = p;
        rng[id.x] = state;
        leftSteps[id.x] += left;
        atomicAdd(&stats[0], params.steps);
        atomicAdd(&stats[1], accepted);
      }
    `,

      // The map: how often walkers have been in each place, with contour lines of the

          vec4f(corner, 0.0, 1.0),

      @fragment
      fn mapFragment(in: Out) -> @location(0) vec4f {
        // The mean count over the bin and its eight neighbours, so a few visits
        // read as a soft patch and not as single specks
        let cell = vec2i(in.uv * vec2f(${binsX}.0, ${binsY}.0));
        var total = 0u;
        for (var dy = -1; dy <= 1; dy++) {

            let x = clamp(cell.x + dx, 0, ${binsX - 1});
            let y = clamp(cell.y + dy, 0, ${binsY - 1});
            total += counts[u32(y) * ${binsX}u + u32(x)];
          }
        }
        let density = clamp(f32(total) / 9.0 * params.heatScale, 0.0, 1.0);

        // The landscape's height as a grey tint, and over it, in the brand red, how
        // often walkers have been there: the more visits the less you see through it
        let p = vec2f((in.uv.x - 0.5) * 2.0 * ${halfWidth}, (0.5 - in.uv.y) * 2.0 * ${halfHeight});
        let h = height(p);
        let ground = mix(vec3f(0.102), vec3f(0.24, 0.235, 0.23), pow(clamp(h, 0.0, 1.0), 0.8));
        // #FF4834

        let gy = height(p + vec2f(0.0, e)) - h;

        @location(0) colour: vec4f,

      @vertex

      // A walker's trail: one segment per instance, between where it was s steps ago
      // and s + 1 steps ago, fading with age
      @vertex
      fn trailVertex(
        @location(0) corner: vec2f,
        @builtin(instance_index) i: u32,

        let w = i % params.walkers;
        let s = i / params.walkers;
        let a = history[((params.head + ${2 * trail}u - 1u - s) % ${trail}u) * ${maxWalkers}u + w];
        let b = history[((params.head + ${2 * trail}u - 2u - s) % ${trail}u) * ${maxWalkers}u + w];

        let cb = vec2f(b.x / ${halfWidth}, b.y / ${halfHeight});
        // Work in square units so the line has the same width in every direction
        let squash = vec2f(${16 / 9}, 1.0);
        let pa = ca * squash;
        let pb = cb * squash;
        let along = pb - pa;
        let length = max(sqrt(dot(along, along)), 1e-6);
        let normal = vec2f(-along.y, along.x) / length;
        let point = mix(pa, pb, corner.x * 0.5 + 0.5) + normal * corner.y * 0.0035;
        // Hide zero-length segments (a rejected step) and jumps across the map's edge
        let jump = any(abs(a - b) > halfSize);
        let hidden = jump || length < 1e-5;
        let fade = 0.6 * (1.0 - f32(s) / f32(params.shown));
        return DotOut(
          vec4f(select(point / squash, vec2f(10.0, 10.0), hidden), 0.0, 1.0),
          vec4f(0.91, 0.886, 0.878, fade),
        );

      @fragment
      fn dotFragment(in: DotOut) -> @location(0) vec4f {
        return in.colour;

  function receive(buffer, taken) {
    const view = new Uint32Array(buffer);
    if (taken === 0) return;

    // Each walker's own share of its time in the left half. Their average is the
    // estimate, and their spread, over the square root of how many there are, is
    // how far it can be trusted: the steps of one walker are not independent, but
    // the walkers are.
    const base = bins + 2;
    let sum = 0;
    let sumSquares = 0;
    for (let k = 0; k < walkers; k++) {
      const share = view[base + k] / taken;
      sum += share;
      sumSquares += share * share;
    }
    const estimate = sum / walkers;
    const sigma =
      walkers > 1
        ? Math.sqrt(Math.max(0, (sumSquares - walkers * estimate * estimate) / (walkers - 1)) / walkers)
        : null;

    // The share of the time in each strip, from the counts of every bin
    const mine = new Float64Array(strips);
    const total = taken * walkers;
    for (let j = 0; j < binsY; j++) {
      for (let i = 0; i < binsX; i++) {
        mine[Math.floor(i / perStrip)] += view[j * binsX + i] / total;
      }
    }
    visited = mine;

    // The busiest place on the map, by the same 3 x 3 mean the picture shows
    let best = 0;
    for (let j = 1; j < binsY - 1; j++) {
      for (let i = 1; i < binsX - 1; i++) {
        const at = j * binsX + i;
        const around =
          view[at - binsX - 1] + view[at - binsX] + view[at - binsX + 1] +
          view[at - 1] + view[at] + view[at + 1] +
          view[at + binsX - 1] + view[at + binsX] + view[at + binsX + 1];
        if (around > best) best = around;
      }
    }
    busiest = { count: best / 9, taken };
    const proposed = view[bins];
    acceptance = proposed > 0 ? view[bins + 1] / proposed : null;

    const last = series[series.length - 1];
    if (!last || taken >= 1.15 * last.steps) series.push({ steps: taken, estimate, sigma });
    drawCharts();
  }

  // Start counting again, with the walkers where they are
  function recount() {
    epoch++;
    stepsTaken = 0;
    owed = 0;
    acceptance = null;
    visited = null;
    busiest = { count: 0, taken: 0 };
    series.length = 0;
    device.queue.writeBuffer(buffers.proposals, 0, new Float32Array(maxWalkers * 4));
    device.queue.writeBuffer(buffers.counts, 0, new Uint32Array(bins));
    device.queue.writeBuffer(buffers.stats, 0, new Uint32Array(2));
    device.queue.writeBuffer(buffers.leftSteps, 0, new Uint32Array(maxWalkers));
    drawCharts();
  }
  // Place the walkers, with every row of their history at the start so no trail shows
  function place() {
    const start = startPositions();
    const rows = new Float32Array(trail * maxWalkers * 2);
    for (let row = 0; row < trail; row++) rows.set(start, row * maxWalkers * 2);
    device.queue.writeBuffer(buffers.positions, 0, start);
    device.queue.writeBuffer(buffers.history, 0, rows);
    head = 0;
  }
  // Start again, with the walkers back at random places
  function reset() {
    walkers = Math.round(10 ** walkersInput.value);
    place();
    recount();
  }
  // A new rule or step size changes where the walkers settle, so what was counted
  // under the old one no longer applies
  walkersInput.addEventListener("input", reset);
  invalidation.then(() => walkersInput.removeEventListener("input", reset));
  for (const input of [stepInput, ruleInput]) {
    input.addEventListener("input", recount);
    invalidation.then(() => input.removeEventListener("input", recount));
  }
  const resetButton = ui.button({ label: "Restart", onClick: reset });
  const readout = ui.readout();
  place();
  drawCharts();

  function frame(ms) {
    // Seconds since the last frame, capped so a pause does not become a flood
    const dt = lastTime === null ? 0 : Math.min((ms - lastTime) / 1000, 0.1);
    lastTime = ms;
    owed += 10 ** rateInput.value * dt;
    const steps = Math.floor(owed);
    owed -= steps;
    stepsTaken += steps;
    head += steps;

    // A count to a brightness: the busiest bin at the last read, grown in proportion
    // to the steps since, is full. Before the first read, the tallest hill's top.
    const heatScale =
      stepsTaken === 0
        ? 0
        : busiest.count > 0
          ? busiest.taken / (busiest.count * stepsTaken)
          : exactTotal / (stepsTaken * walkers * peak);

    paramView.setFloat32(0, stepInput.value, true);
    paramView.setUint32(4, steps, true);
    paramView.setUint32(8, walkers, true);
    paramView.setUint32(12, ruleInput.value, true);
    paramView.setFloat32(16, heatScale, true);
    paramView.setUint32(20, head, true);
    // A shorter trail the faster it goes, so it stays readable: 120 steps at a few
    // steps a second, 30 at a hundred
    const shown = Math.round(
      Math.min(120, Math.max(30, 400 / Math.sqrt(10 ** rateInput.value))),
    );
    paramView.setUint32(24, shown, true);
    device.queue.writeBuffer(buffers.params, 0, paramBytes);

    const encoder = device.createCommandEncoder();
    if (steps > 0) {
      const compute = encoder.beginComputePass();
      compute.setPipeline(walkPipeline);
      compute.setBindGroup(0, walkBindGroup);
      compute.dispatchWorkgroups(Math.ceil(walkers / groupSize));
      compute.end();
    }

    const pass = gpu.beginRenderPass(encoder, context);
    pass.setVertexBuffer(0, cornerBuffer);
    pass.setPipeline(mapPipeline);
    pass.setBindGroup(0, mapBindGroup);
    pass.draw(6);
    pass.setPipeline(dotPipelines[0]);
    pass.setBindGroup(0, trailBindGroup);
    pass.draw(6, walkers * (shown - 1));
    pass.setPipeline(dotPipelines[1]);
    pass.setBindGroup(0, rejectedBindGroup);
    pass.draw(6, walkers);
    pass.setPipeline(dotPipelines[2]);
    pass.setBindGroup(0, walkerBindGroup);
    pass.draw(6, walkers);
    pass.end();

    const sample = !readback.pending && ++frameCount % sampleEvery === 0 && stepsTaken > 0;
    if (sample) readback.copy(encoder);
    device.queue.submit([encoder.finish()]);
    if (sample) {
      const mine = epoch;
      const taken = stepsTaken;
      readback.read((buffer) => {
        if (mine !== epoch) return; // from before a reset
        receive(buffer, taken);
      });
    }

    if (frameCount % 6 === 0) {
      readout.textContent =
        `${stepsTaken.toLocaleString()} steps each · ` +
        (acceptance === null ? "accepted –" : `${(100 * acceptance).toFixed(0)}% accepted`) +
        (currentText() ? ` · ${currentText()} (exact ${exactLeft.toFixed(3)})` : "");
    }
  }

  gpu.run(invalidation, device, frame);

  // The canvas with the controls laid over its corner
  yield ui.stage(canvas, [walkersInput, stepInput, ruleInput, rateInput, resetButton, readout]);
}

Analysis

The left chart is for one number, as the π and the fractal were: the share of the time the walkers spend in the left half of the map. The left hill is tall and narrow and the right one is low and wide, and the right holds more so the exact answer is below a half. The chart is the walkers’ estimate as the steps pile up, with its uncertainty (the walkers differ from one another and that spread is how far to trust it) and the exact value dashed.

The right chart is the same thing in more detail: the share of the time in each vertical strip of the map, against what it ought to be (the dashed line). It is the two hills seen from the side.

The first stretch of steps is the walkers finding the hills, so the estimate starts far off. At a small step a walker rarely crosses the gap between the hills and its time is split by where it began and not by how high the ground is: more walkers, or a larger step, fixes that.
